# UIDAI Data Hackathon 2026  
## Understanding Aadhaar Enrolment and Update Trends Across India

This repository contains the analysis developed for the UIDAI Data Hackathon 2026.  
The project explores patterns in Aadhaar enrolments, demographic updates, and biometric updates using aggregated and anonymised datasets.

The objective is to identify meaningful trends and indicators that can support data-driven decision-making for service optimisation and resource planning.

---

## Problem Statement
Aadhaar enrolment numbers alone do not capture ongoing system usage.  
This project examines how enrolments and update activities vary across age groups and states, and introduces update intensity as an indicator of administrative demand.

---

## Methodology
- Data preprocessing and aggregation using Python and Pandas  
- Univariate analysis for age-wise and state-wise distributions  
- Bivariate analysis to compare enrolments with update volumes  
- Visualization of key trends using Matplotlib  

---

## Key Insights
- Aadhaar enrolments are primarily driven by child and adolescent registrations  
- Some states show high update activity relative to enrolments  
- Demographic and biometric updates are positively correlated  
- Update intensity ratios highlight regions with higher administrative interaction
